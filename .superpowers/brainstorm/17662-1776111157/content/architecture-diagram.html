Event Flow

Each scan layer emits typed events through a shared EventEmitter. The WebSocket server forwards them to the browser. D3 processes each event type differently:

recon:route → add node to Frontend lane
recon:endpoint → add node to API lane
recon:datamodel → add node to Database lane
recon:envvar → add badge to referencing node
rules:finding → color shift + badge + pulse
probe:finding → confirmed finding highlight
ai:finding → AI-detected vulnerability
scan:complete → transition to exploration mode
