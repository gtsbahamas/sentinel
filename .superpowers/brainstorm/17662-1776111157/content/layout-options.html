A: Layered Stack

Horizontal layers stacked vertically. Frontend top, backend middle, database bottom, external services to the side. Nodes appear within their layer. Matches the mental model from the coaching curriculum.

Pros

  • Intuitive for beginners
  • Maps directly to the session's stack diagram
  • Clear top-to-bottom data flow

Cons

  • Can feel static/boxy
  • Connections between layers are simple lines
FORCE-DIRECTED NETWORK GRAPH

B: Force-Directed Graph

Nodes float and self-organize based on connections. Clusters form naturally around related components. Nodes repel/attract based on relationships. Classic D3 force simulation.

Pros

  • Visually dynamic and impressive
  • Organic animation as nodes appear
  • Shows relationship density naturally

Cons

  • Can be chaotic with many nodes
  • Harder for beginners to parse
  • Layout is non-deterministic

C: Hybrid (Layered Lanes + Force)

Vertical lanes for each layer (Frontend, API, Database, External). Within each lane, nodes use force simulation to arrange organically. Connections draw across lanes. Structure of A, dynamism of B.

Pros

  • Best of both: structured AND dynamic
  • Layer context always visible
  • Nodes animate within their lane
  • Cross-lane connections show data flow

Cons

  • Slightly more complex to implement
  • Lane width needs to adapt to node count
